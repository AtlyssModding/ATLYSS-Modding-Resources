# README
Maxed out character profiles and bank storages across major game versions. Follow the [**how to backup Saves & file editing**](https://github.com/AtlyssModding/ATLYSS-Modding-Resources/wiki/How-to-backup-saves-&-file-editing) guide to learn how to use it, the same information and techniques showcased there were used here.

Beta 1.6.2B will require the original [MoreBankTabs](https://thunderstore.io/c/atlyss/p/16MB/MoreBankTabs/).\
Different versions of [**MoreBankTabsFixed**](https://thunderstore.io/c/atlyss/p/SnivyXXY/MoreBankTabsFixed/versions/) were used for compatibility.
- `82025.a2` (Designed for 1.0.1 but 2.0.1 is fine)
- `102025.a5` (Designed for 2.0.1 but 1.0.1 is fine for equipment)
- `112025.a4` (Equipment is accessible without the mod, otherwise 2.1.1)
