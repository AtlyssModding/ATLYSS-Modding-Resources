## Additional Information
**Item Templates** and **Icons Render** are a set of tools for easily creating items, they're based off the Homebrewery User Manual but designed for active development instead. `ATLYSS_HEADS_TEMPLATE.glb` is a 3D mesh template for creating [Helm Renders](https://github.com/Catman-232/Homebrewery/wiki/Properties-that-only-Helms-have#_helmrender). ([**_helmOverrideMesh**](https://github.com/Catman-232/Homebrewery/wiki/Properties-that-only-Helms-have#_helmoverridemesh))

**LimitCFGs** and **JiggleSettings** are preset collections that go into `BepInEx\config\Homebrewery`.\
The presets handle it but enabling HB's custom jiggle settings requires turning on "CustomJiggleOn" in `JiggleSettings.CFG`\
LimitCFGs require you configure "SliderRangeOverride" and "ClampPlayerProportions" in `Homebrewery.CFG`'s **[Sliders]** section.

**HB Phone Template** is for customising HB's "Based Department" easter egg which you can call with `/hb [call/phone] based`. Inside is the text and icon files used in-game, edit and replace them in: `BepInEx\plugins\Catman232-Homebrewery\Internal`.
