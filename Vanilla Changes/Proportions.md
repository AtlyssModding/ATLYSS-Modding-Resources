Overview of proportion value changes across versions. documentation for both [**_appearanceprofile**](https://github.com/AtlyssModding/ATLYSS-Modding-Resources/wiki/How-to-backup-saves-&-file-editing#_appearanceprofile) and [**Homebrewery LimitCFGs**](../Homebrewery/LimitCFGs).\
The **Limit Player Character Proportions** option (removed in July 2025) set max Boobs/Butts to 40 and Belly to 35 on all races.
- Universal values across races and versions:
```
- Hue 0/360
- Saturation 0/2
- Voice Pitch 0.6/1.25
```
